# Ishu English Quest

A mobile-friendly 7th-grade English learning app built around mythology and Percy Jackson-inspired themes.

## MVP
- Student quest dashboard
- Reading comprehension and inference practice
- Point-of-view lesson
- XP and completion tracking
- Parent progress snapshot
- Responsive mobile layout

## Roadmap
1. Add the full Lightning Thief skills sequence without reproducing copyrighted text.
2. Add vocabulary, grammar, and writing quests.
3. Persist progress per student.
4. Add a parent dashboard with skill trends and missed-question analysis.
5. Add adaptive difficulty and weekly progress summaries.

## Run locally
Open `index.html` in a browser. No build step or dependency installation is required for the current MVP.
